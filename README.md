# Oskar's Daily Brief
Static site (GitHub Pages, main branch root). No build step.
## Add a brief
1. Copy `template.html` to `briefs/YYYY-MM-DD.html`, fill `{{DATE}}`, `{{DATE_LONG}}`, content.
2. In `index.html`: update the "Latest" link/headline and add an `<li>` under `<!-- ARCHIVE: newest first -->`.
3. Commit and push to `main`.
